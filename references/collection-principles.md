# 采集原理参考

当用户要求解释采集原理、设计新平台采集链路、判断用页面解析还是接口解析时，读取本文件。

## 采集的本质

商品采集不是“猜字段”，而是把用户在浏览器里能看到或页面公开提供的数据，经过识别、解析、归一化、保存和导出，变成稳定的数据记录。

典型链路：

1. 识别平台和页面类型。
2. 从搜索页 / 分类页提取商品入口和基础字段。
3. 把商品加入队列，做去重、价格过滤和数量限制。
4. 请求或读取详情页。
5. 从结构化数据、公开接口、DOM 和 meta 中合并字段。
6. 做字段归一化、图片 URL 标准化和错误兜底。
7. 保存记录，导出 Excel / JSON。

## 页面解析和接口解析

### 页面解析

页面解析指从当前 HTML、内嵌 JSON、DOM、meta 标签中提取数据。

优点：

- 更接近用户可见数据。
- 不一定需要额外接口信息。
- 适合浏览器扩展 content script。

缺点：

- DOM 类名和页面结构容易变。
- SPA 页面可能需要等待渲染完成。
- 有些字段可能只在接口返回中出现。

### 接口解析

接口解析指使用商品详情 API、搜索 API、店铺 API 等返回的 JSON。

优点：

- 字段更完整，结构更稳定。
- 更容易解析变体、库存、销量、店铺等复杂字段。

缺点：

- 接口可能需要登录态、签名、CSRF、设备参数或地区参数。
- 私有接口可能变化或受平台限制。
- 不能把用户敏感 token、Cookie、账号信息硬编码进代码。

### 推荐优先级

1. 公开结构化数据：JSON-LD、公开页面状态、meta。
2. 用户提供且合规可用的公开详情 API。
3. 当前浏览器会话可访问的页面请求，由 background/service worker 代请求。
4. DOM 兜底。
5. 列表卡片兜底，生成部分成功记录。

## 搜索页采集原理

搜索页负责发现商品和提供基础数据：

- 商品链接
- 商品 ID
- 标题
- 主图
- 价格和币种
- 店铺名或地区信息，如果卡片有展示

搜索页不要依赖单一选择器。应先找到商品卡片容器，再从卡片中找链接、图片、价格和标题。

常见去重键：

- 平台 + 商品 ID
- 平台 + 店铺 ID + 商品 ID
- 标准化 URL

## 详情页采集原理

详情页负责补齐复杂字段：

- 描述
- 图片列表
- 属性和规格
- 变体
- 销量
- 库存
- 上架时间
- 商家名称、商家 ID、店铺 URL
- 类目
- 公开联系方式

解析顺序：

1. 页面初始状态对象。
2. JSON-LD。
3. 商品详情 API。
4. DOM。
5. meta 标签。
6. 搜索页 task 兜底数据。

每个字段都要单独容错，某个字段失败不能导致整条商品失败。

## 商品详情 API 地址

如果用户提供商品详情 API 地址，先确认这些信息：

- API 是否公开可访问。
- 是否必须登录。
- 是否依赖 Cookie、Authorization、CSRF、签名、时间戳、设备 ID。
- 请求方法是 GET 还是 POST。
- URL 参数或 body 参数如何从商品 URL 中生成。
- 返回字段中哪些对应商品字段。
- 是否有地区、语言、币种参数。

不要把敏感鉴权信息写入代码。浏览器扩展可以使用当前页面登录态发起同源或 host-permission 允许的请求，但仍要避免绕过平台限制。

## 商城地址与地区

平台采集通常需要明确商城地址和地区，例如：

- Shopee 新加坡：`https://shopee.sg`
- Shopee 马来西亚：`https://shopee.com.my`
- Temu 美国：`https://www.temu.com`
- MercadoLibre 墨西哥：`https://www.mercadolibre.com.mx`

同一平台不同国家站点可能字段、币种、语言、URL 规则和接口参数都不同。不要只写 `shopee.com` 就假设所有站点可用。

## 自动采集原理

自动采集是“扫描当前页 -> 入队 -> 执行队列 -> 不足目标时翻页 -> 继续扫描”。

关键点：

- 入队前做价格过滤和去重。
- 队列执行完成后再翻页。
- 翻页后等待商品列表加载稳定。
- 目标数量要扣除已采集、正在采集和等待队列。
- 并发要可配置且保守。

## 日志原理

日志用于解释采集器正在做什么，不是数据存储。

建议记录：

- 加入队列
- 正在采集
- 成功 / 失败 / 部分成功
- 已采集数量、剩余数量、队列数量、正在采集数量
- 翻页和自动采集结束原因

日志必须有上限，例如最多 100 条，超过后清除旧日志。
